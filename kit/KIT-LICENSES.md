of the grammar library also beside it in `grammar/`. `MANIFEST` lists each file's size and sha256, says which files
git holds and which `verify_kit.sh` makes, and marks the files that are byte for byte the same as in our two-node kit
v0.6.1 with recipe #13 (the same `dsv41` family). `SHA256SUMS` is the same list for `sha256sum -c`.
